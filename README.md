# Círculo — protótipo navegável (versão para celular / iPhone X)

Versão responsiva do protótipo do TCC "Círculo" (Design — PUC-Rio).
No celular, o app ocupa a largura toda da tela e se ajusta à altura disponível,
respeitando o notch e a barra de início do iPhone.

**Melhor experiência no iPhone:** abra o link no Safari, toque em Compartilhar →
"Adicionar à Tela de Início" e abra pelo ícone do Círculo. Assim ele roda em tela cheia,
sem as barras do navegador.

Abra `index.html` (ou `Prototipo.dc.html`).
